The epoch does not make these rows younger, and it does not make them less real. Age derives from the advisory date, so an ID that went public 519 days ago is 519 days old whether or not this site counts it. The epoch exists so the headline measures what has happened since launch rather than carrying a backlog accumulated while feed coverage was still changing underneath it.

A filter that removes the oldest and strongest evidence has to be visible rather than quietly applied, which is what this page is for. Without it the epoch would delete this project's best evidence from the site with no home anywhere. No CNA is named on these rows, at any age: they are outside the reportable set, so they are outside the set this site is willing to attribute.
