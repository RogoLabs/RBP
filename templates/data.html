Stable URLs, rebuilt every six hours. Others building on this is the point.

FileContents
rbp.json Every reportable row, full field set.
rbp.csv The same rows, gated identically to the tables. The owner column here never names a CNA the site withholds.
summary.json Headline counts, age buckets, rule split, inference precision, feed health.
cnas.json Per-CNA aggregation. Descriptive only, no thresholds.
precision.json The grader ledger: predictions, verdicts, and the misses.
data/cna/<slug>.json One file per named CNA, so anyone can pull just their own rows.

Reading these honestly

  • Counts are a floor. Only configured feeds are read, so an RBP in an uninstrumented ecosystem does not appear.
  • Owner is inferred and absent wherever the gate did not pass. It is never an authoritative assignment.
  • Days public is a floor measured from the earliest advisory visible here, not the rule's awareness clock.
  • A {{ rule_must }} reading is a candidate, never an established breach.
  • Full method and current accuracy: Method.

On the description column. An earlier version of this page called these “advisory titles, reproduced verbatim” and claimed no vulnerability detail beyond a title appears here. Neither was accurate. The field is the first 180 characters of whatever text the feed supplied, which is often a body rather than a title, some entries are cut mid-word, and for some rows that text describes a mechanism. Every character of it was already published by the feed it came from, and nothing here is original analysis, but it is a truncated summary and not a title.
