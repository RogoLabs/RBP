Showing up in What it is

Days public is a floor. It counts from the earliest advisory this site can see. The rule's clock starts when the CNA became aware, which is not observable from outside, so this column says how long an ID has been public and never how overdue it is.

No row here names a CNA. The reservation endpoint returns [REDACTED] for this population, and the reconstruction that could often fill it in is run and measured but not published: its live sample is too small to put a name on a public row. That is a deliberate limit, and the method page gives the measurement behind it.

Most named rows rest on a single source. The headline core requires two independent origins, but naming a CNA required only that inference succeeded, so the more consequential claim was held to the weaker standard.
