A Reserved but Public CVE ID is one a CNA has reserved and that appears in a public advisory, while the CVE Record itself is still unpublished. Anyone pulling the CVE List sees nothing; the world already knows.

On 13 August 2026 the CVE Board approved RBP Policy v2.0.0. It sets a clear expectation. A record should be published within 72 hours of disclosure. Then it hands enforcement entirely to discretion: warnings, reservation caps, intervention, formal review, each of which may be applied.

Discretion exercised in private is indistinguishable from no enforcement at all. There is no public list of RBPs, no public notification record, no public enforcement log. The Program's own RBP metrics page still promises figures “from 2017 to present” and stops in Q3 2021.

And the accountability field is withheld. Ask the CVE Services API about a reserved ID and it returns the state, then redacts the CNA that reserved it: "owning_cna": "[REDACTED]", though CNA Rule 4.5.1.7 lets the Secretariat name that CNA 24 hours after public disclosure.

This site is being built to publish the outside view.
